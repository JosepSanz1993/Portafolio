# Josep Sanz Gallego — Portafolio Red Team

Portafolio interactivo de **Pentester / Red Team Junior** (hacking ético).

- Terminal interactiva: escribe `help`.
- Hay 3 flags escondidas. Entrégalas con `submit flag{...}`.

## Publicar en GitHub Pages

1. Crea un repositorio, por ejemplo `portfolio` (o `JosepSanz1993.github.io` para tenerlo en la raíz).
2. Sube `index.html` y `CV_Josep_Sanz_Ciberseguridad.pdf` a la raíz del repositorio.
3. Ve a **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En uno o dos minutos estará en `https://josepsanz1993.github.io/portfolio/`.

> Todo el contenido ofensivo referenciado se ha realizado en laboratorios propios o plataformas que autorizan el ataque.
